# Avance UX/UI: Pagina Publica

## Objetivo

Convertir la vista publica de MALIS NAILST en una landing de conversion conectada al flujo de reserva online.

La pantalla debe ayudar a:

- Entender rapidamente que ofrece el salon.
- Ver servicios principales con precios desde.
- Generar confianza antes de solicitar una cita.
- Llevar a la clienta hacia `Reserva en linea`.

## Cambios Aplicados

- Se reemplazo la portada simple por una landing completa.
- Se agrego hero con mensaje comercial claro y CTA de reserva.
- Se agrego boton para ir a servicios dentro de la misma pagina publica.
- Se agrego bloque de servicios principales con fallback estatico.
- Se conecto el bloque de servicios publicos a la tabla `services` de Supabase.
- Se agrego bloque de experiencia y confianza.
- Se agrego galeria visual provisional con placeholders consistentes.
- Se agrego bloque de contacto, horario y ubicacion.
- Se agrego CTA fijo en mobile para reservar.
- Se agrego SEO basico: description, Open Graph, Twitter Card, theme color y favicon SVG.
- Se agrego skip link para navegacion por teclado.
- Se agrego footer publico simple con estado legal pendiente y acceso a reserva.
- Se agregaron transiciones, foco visible y soporte para movimiento reducido.
- Se agrego textura sutil en la pagina publica para evitar superficies planas.

## Criterio UX

La pagina publica ahora responde:

1. Que ofrece MALIS NAILST?
2. Cuanto cuesta empezar?
3. Por que reservar aqui?
4. Como solicito una cita?

## Siguientes Ajustes Recomendados

- Reemplazar placeholders por fotos reales del salon y trabajos.
- Agregar direccion real y telefono real.
- Agregar galeria administrable desde Supabase Storage.
- Agregar testimonios reales si el negocio los tiene.
- Reemplazar la imagen Open Graph provisional por una imagen real de marca.
- Crear paginas reales de privacidad y terminos cuando el negocio defina esos textos.
